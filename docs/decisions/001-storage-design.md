# ADR-001 — Storage design

- **상태:** 채택 (초기 범위)
- **결정:** 기존 JSON/JSONL 산출 및 현재 DB/파일 흐름을 유지하며, 새로운 그래프 DB로 전면 마이그레이션하지 않는다.
- **이유:** 남은 개발 기간이 제한적이고, 첫 번째 연구 목표는 저장 엔진 자체가 아니라 관계 기반 대상 후보 발굴의 정확도 평가다.
- **원칙:** 원본 참조·이벤트 ID·엔터티 ID·엣지 ID는 안정적으로 유지한다. 이벤트와 관계를 명시적으로 저장할 수 있는 관계형 구조를 우선 검토한다.
- **비교 실험:** Markdown과 DB 비교는 같은 증거·질의·모델·입력 예산을 사용하고 적재/인덱싱 비용까지 포함한다.
- **재검토 조건:** 관계 탐색의 병목이 실측으로 확인되고 관계형 저장 구조로 성능·유지보수 요구를 충족할 수 없을 때 그래프 DB 도입을 재검토한다.
